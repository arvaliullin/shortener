# 1. Пакет net/http. Работа c HTTP

## Создание HTTP-сервера

```go

package main

import "net/http"

func main() {
	if err := http.ListenAndServe(`:8080`, nil); err != nil {
		panic(err)
	}
}

```

## Обработка HTTP-запросов

- [http.Handler](https://pkg.go.dev/net/http#Handler) - интерфейсный тип с методом для обработки HTTP-запроса;
- [http.ResponseWriter](https://pkg.go.dev/net/http#ResponseWriter) - интерфейс потоковой записи, куда обработчик пишет ответные данные для клинта;
- [http.Request](https://pkg.go.dev/net/http#Request) - даные запроса.

```go

package main

import "net/http"

type MyHandler struct {
}

func (h MyHandler) ServeHTTP(w http.ResponseWriter, _ *http.Request) {
	data := []byte("hello")
	w.Write(data)
}

func main() {
	var handler MyHandler
	if err := http.ListenAndServe(`:8080`, handler); err != nil {
		panic(err)
	}
}

```

## Маршрутизация запросов

```go
package main

import (
	"io"
	"net/http"

	"github.com/go-chi/chi/v5"
)

func mainPage(w http.ResponseWriter, _ *http.Request) {
	io.WriteString(w, "Привет!")
}

func apiPage(w http.ResponseWriter, _ *http.Request) {
	io.WriteString(w, "Это страница /api")
}

func main() {
	router := chi.NewRouter()

	router.Get(`/`, mainPage)
	router.Get(`/api`, apiPage)

	if err := http.ListenAndServe(`:8080`, router); err != nil {
		panic(err)
	}
}

```
